# SincroVoz

**Corrige automáticamente la voz desfasada de tus videos, sin perder calidad.** Programa para Windows 8.1, 10 y 11.

- Sincronización automática de voz y video (también desfases que crecen con el tiempo)
- Recorte en la línea de tiempo, sin volver a comprimir la imagen
- Quitar ruido de fondo y normalizar el volumen para redes (−14 LUFS)
- Extraer el audio en WAV, MP3 o pista original
